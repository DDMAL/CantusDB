# Country data sources

Migration `0048_getty_countries` uses preferred names and numeric identifiers
from the Getty Thesaurus of Geographic Names, checked on 2026-11-15. The
J. Paul Getty Trust, Getty Research Institute makes this data available under
the Open Data Commons Attribution License. [Getty TGN](https://www.getty.edu/research-conservation/tools-databases/vocabularies/tgn/) · [ODC Attribution License](https://opendatacommons.org/licenses/by/1-0/)

The migration includes RISM country prefixes used in library sigla. For
example, `ZA` identifies South Africa and `RC` identifies Taiwan.
[RISM Library Sigla, p. 179](https://rism.info/fileadmin/content/site-content/BIBVERZ_2008_10.pdf#page=179) · [RISM Online country list](https://rism.online/countries/list)
